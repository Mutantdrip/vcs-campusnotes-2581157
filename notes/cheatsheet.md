# Git command cheat sheet

| Task | Command |
|------|---------|
| Link a remote | `git remote add origin <url>` |
| Push and track | `git push -u origin <branch>` |
| Update from remote | `git pull` |
| Lightweight tag | `git tag v0.1.0` |
| Annotated tag | `git tag -a v1.0.0 -m "msg"` |
| Push tags | `git push origin --tags` |
